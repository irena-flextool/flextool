    Model formulation

    Every constraint, variable and objective term of the FlexTool LP, taken from the EQ. / VAR. / OBJ. headers in the model code. Each entry names the source file and line it was generated from. Names in braces expand: maxOnline_{linear,integer} is maxOnline_linear and maxOnline_integer, {sfx} is _linear / _integer, and a part in square brackets is optional (co2_max_total[_path]). Capacities are in MW (MWh for storage) and costs in CUR, the default units of FlexTool (see Model parameters).

    Capacity symbols used in the headers

    For a unit, connection or storage node e in period d:

    • capacity[e,d] = existing[e,d] × virtual_unitsize[e] when virtual_unitsize is set, else existing[e,d] (MW, or MWh for storage). With virtual_unitsize, existing is the number of units.
    • unitsize[e] = virtual_unitsize[e], else existing (the largest period value), else 1000.
    • existing_count[e,d] = capacity[e,d] / unitsize[e]: equal to existing when virtual_unitsize is set; otherwise 1 (less in a period whose existing is below the largest, 0 without existing capacity).
    • invest_*, retire_*, cumulative_*, invest_forced and the capacity a construction lead time carries are MW (MWh) in every case. v_invest and v_divest are continuous, in units of unitsize.

    Core model

    FlexTool LP model: builds the FlexTool LP from FlexData d into a polar_high Problem m.

    VAR. v_flow

    v_flow[p,source,sink,d,t] ≥ 0   ∀ (p,source,sink,d,t) ∈ pss_dt

    Flow on a process arc in units of unitsize: MW = v_flow · unitsize[p]. Input arcs of indirect units without invest/divest variables carry a per-element upper bound (their capacity is a constant); maxFlow caps every other arc.

    Source: flextool/engine/model/core.py:911 (_declare_variables)

    VAR. v_flow (coarse processes)

    Names: v_flow

    v_flow[p,s,k,d,b] ≥ 0   ∀ p ∈ processCoarse, (p,s,k) arcs, (d,b) the coarse steps of p (b = first fine step)

    The flow of a coarse process: one rate per coarse step, the same on its fine steps. b.v_flow is indexed on every fine step (_coarse_flows.alias): a fine row of a coarse process reads its step's column.

    Source: flextool/engine/model/core.py:918 (_declare_variables)

    VAR. v_ramp_up / v_ramp_down

    Names: v_ramp_up, v_ramp_down

    v_ramp_up[p,s,k,d,t] ≥ 0, v_ramp_down[p,s,k,d,t] ≥ 0   ∀ (p,s,k,d,t) ∈ R
  R = the rows of ramp_change_eq (_ramp_cost_rows): (p,s,k) ∈ process_source_sink_ramp_cost with a ramp
  predecessor at (d,t) (dt_ramp_link or dt_ramp_carry; for a coarse process t = b, its coarse step)

    The increase and the decrease of v_flow from the ramp predecessor, in units of unitsize (as v_flow). Priced equally by the ramp cost, so at most one of them is > 0 at an optimum (up + down = |Δv_flow|). Declared only when some arc has a ramp cost.

    Source: flextool/engine/model/core.py:929 (_declare_variables)

    VAR. vq_state_up / vq_state_down

    Names: vq_state_up, vq_state_down

    vq_state_up[n,d,t], vq_state_down[n,d,t] ≥ 0
  ∀ n ∈ nodeBalance ∪ nodeBalancePeriod, (d,t) ∈ dt

    Balance slack in MW (shortfall / surplus); enters the balance times step_duration and is penalised in the objective. Nodes with penalty_method = off have none, so their balance is a hard equality.

    Source: flextool/engine/model/core.py:944 (_declare_variables)

    VAR. v_state

    v_state[n,d,t] ≥ 0   ∀ (n,d,t) ∈ nodeState_dt

    Storage state in units of the node's state unitsize: MWh = v_state · state_unitsize[n]. Its upper bound depends on invest/divest and is the maxState row.

    Source: flextool/engine/model/core.py:955 (_declare_variables)

    VAR. v_state_inter / v_state_rp_start

    Names: v_state_inter, v_state_rp_start

    v_state_inter[n,d,b] ≥ 0        ∀ n ∈ nodeState_rp, (d,b) ∈ rp_base_period
v_state_rp_start[n,d,t] ≥ 0     ∀ n ∈ nodeState_rp, (d,t) ∈ rp_block_first

    Representative-period storage, in state units: the state at the end of base period b of period d, and the free starting state of each representative block. Every period has its own base periods (two periods may share base-period names). Upper bounds are the rows rp_inter_period_max_state and maxState_rp_start.

    Source: flextool/engine/model/core.py:964 (_declare_variables)

    VAR. v_invest_p / v_divest_p / v_invest_n / v_divest_n

    Names: v_invest_p, v_divest_p, v_invest_n, v_divest_n

    v_invest_p[p,d] ≥ 0 ∀ (p,d) ∈ pd_invest_set;  v_divest_p[p,d] ≥ 0 ∀ (p,d) ∈ pd_divest_set
v_invest_n[n,d] ≥ 0 ∀ (n,d) ∈ nd_invest_set;  v_divest_n[n,d] ≥ 0 ∀ (n,d) ∈ nd_divest_set

    Capacity built / retired in period d, as a count of unitsize (process) or state unitsize (storage node). Only pre-existing capacity can be retired: pd/nd_divest_set hold the periods where the entity has some (before its end of life). Upper bounds are the maxInvest_var_bound / maxDivest_var_bound rows.

    Source: flextool/engine/model/core.py:982 (_declare_variables)

    VAR. v_flow_back

    v_flow_back[p,source,sink,d,t] ≥ 0   ∀ (p,source,sink) ∈ twoway1var_arcs, (d,t) ∈ dt

    Reverse flow (sink → source) of method_2way_1var_off and DC power-flow arcs, in units of unitsize; the signed flow is v_flow − v_flow_back. One variable serves both the balance and dc_flow_eq. A coarse process has one per coarse step, as v_flow.

    Source: flextool/engine/model/core.py:1002 (_declare_variables)
