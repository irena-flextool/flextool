    Results catalogue

    Every result table FlexTool writes, generated from the code. A table is written to output_parquet/<scenario>/<table>.parquet, and with CSV output to output_csv/<scenario>/ under the CSV name of the default output settings. The parquet's top column level is scenario; the levels below it are listed as column levels. Membership sets are flat tables whose first column is scenario, followed by the listed row levels; timeline_breaks is a flat (period, time) table. Units are the default convention of FlexTool (MW, MWh, CUR); see Model outputs for what the results mean and how they are computed.

    Costs

    See Costs in Model outputs.

    annualized_costs_d_p

    Total cost of each period by cost category, scaled to a full year of operation, including the yearly investment, retirement and fixed costs.

    • Files: annualized_costs_d_p.parquet, annualized_costs__d.csv
    • Rows: period; column levels: category
    • every column: M CUR/a, annualized
    • Results database: model entity cost_annualized parameter
    • Counterpart at the other time resolution: costs_dt_p

    costs_discounted_d_p

    Cost of each period by cost category, discounted and multiplied by the years the period represents (the net present value the objective counts).

    • Files: costs_discounted_d_p.parquet, costs_discounted__d.csv
    • Rows: period; column levels: category
    • every column: M CUR, discounted
    • Results database: model entity cost_discounted_solve parameter

    costs_discounted_p_

    Discounted cost by cost category, totalled over all periods of the run.

    • Files: costs_discounted_p_.parquet, costs_discounted.csv
    • Rows: category; column levels: none
    • every column: M CUR, discounted
    • Results database: model entity cost_discounted_total parameter

    costs_dt_p

    Operational and penalty costs incurred in each time step by cost category, in currency (not millions), with the step duration and timestep weight applied and not scaled to a year.

    • Files: costs_dt_p.parquet, costs__dt.csv
    • Rows: period, time; column levels: category
    • every column: CUR, per_step
    • Results database: model entity cost_t parameter
    • Counterpart at the other time resolution: annualized_costs_d_p

    period_share_of_year__d

    Share of a year that each realised period covers; the per-period tables are divided by it to give values per year.

    • Files: period_share_of_year__d.parquet, period_share_of_year__d.csv
    • Rows: period; column levels: param
    • every column: dimensionless, ratio
    • Results database: not written there

    years_represented__d

    Number of years each period represents.

    • Files: years_represented__d.parquet, years_represented__d.csv
    • Rows: period; column levels: param
    • every column: a, count
    • Results database: not written there

    • Rows: period, node; column levels: category
    • every column: M CUR/a, annualized

    • every column: M CUR, discounted

    cost_unit_annualized_d_ec

    Annualized cost of each unit and period by cost category; summed over units, connections and nodes it gives the system annualized costs.

    • Files: cost_unit_annualized_d_ec.parquet, cost_unit_annualized__d.csv
    • Rows: period, unit; column levels: category
    • every column: M CUR/a, annualized

    • Rows: period, unit; column levels: category

    • Results database: unit entity cost_discounted parameter

    Prices

    See Prices in Model outputs.

    co2_price_period_d_g

    Shadow price of the per-period CO2 cap of each group, in the currency of the period (positive when the cap binds).

    • Files: co2_price_period_d_g.parquet, group_CO2_price_period__d.csv
    • Rows: period; column levels: group
    • every column: CUR/t, price
    • Results database: not written there

    co2_price_total_d_g

    Shadow price of the cumulative CO2 cap of each group, in discounted currency per tonne, the same in every period.

    • Files: co2_price_total_d_g.parquet, group_CO2_price_total__d.csv
    • Rows: period; column levels: group
    • every column: CUR/t, price
    • Results database: not written there

    node_prices_dt_e

    Price of energy at each balanced node and time step: the cost of one more unit of demand there (the dual of the node balance), in the price base of the cost inputs.

    • Files: node_prices_dt_e.parquet, node_prices__dt.csv
    • Rows: solve, period, time; column levels: node
    • every column: CUR/MWh, price
    • Results database: node entity price_t parameter

    reserve_prices_dt_ppg

    Price of each reserve, direction and group in each time step: the cost of one more MW of every requirement of the group held for the step.

    • Files: reserve_prices_dt_ppg.parquet, reserve_price__upDown__group__dt.csv
    • Rows: solve, period, time; column levels: reserve, updown, node_group
    • every column: CUR/MW, price
    • Results database: not written there

    • Results database: connection__node__node entity cf parameter

    • Files: unit_inputs_cf_d_ee.parquet, unit_cf__inputNode__d.csv
    • Rows: period; column levels: unit, source
    • every column: dimensionless, ratio
    • Results database: unit__node entity cf parameter

    unit_outputs_cf_d_ee

    Capacity factor of each unit's output flow in each period: the period's flow divided by the unit capacity and the period's hours.

    • Files: unit_outputs_cf_d_ee.parquet, unit_cf__outputNode__d.csv
    • Rows: period; column levels: unit, sink
    • every column: dimensionless, ratio
    • Results database: unit__node entity cf parameter
